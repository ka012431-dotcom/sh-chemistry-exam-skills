# 化學教材評量小遊戲技能 (chemistry-minigames)

將高中化學教材自動轉換為「一重點一小遊戲」的形成性評量網頁，並附上 QR Code，方便教師在課堂上供學生即時掃描作答。

---

## 處理流程

```
1. 分析化學教材 → 2. 提取學習重點與測驗素材（確認） → 3. 設計化學評量小遊戲 HTML
→ 4. 打包 index.html 索引頁 → 5. 上傳至 GitHub → 6. 發佈並提供連結與 QR Code
```

---

## Step 1：分析化學教材，提取重點

分析使用者提供的化學教材，提取 3~6 個核心學習重點。每個重點應設計為一個獨立小遊戲。
高中化學常見的重點提取範例：
- **重點一：元素符號與中文名稱對照**（適合記憶翻牌）
- **重點二：化學反應式係數平衡**（適合填充題或配對題）
- **重點三：重要化學物質的日常用途**（適合配對題）
- **重點四：酸鹼與鹽類常見迷思概念**（適合是非題）
- **重點五：滴定實驗操作步驟**（適合排序題）

---

## Step 2：挑選適用的化學小遊戲類型

根據重點性質，挑選最適合的網頁互動遊戲類型：

| 遊戲類型 | 高中化學科適用情境範例 | 推薦檔名 |
|---------|-----------------------|---------|
| **選擇題 (MCQ)** | 物質性質分類（如：哪些是強電解質、極性分子判定） | `game-mcq.html` |
| **填充題 (Fill-in-Blank)** | 填寫化學式、平衡反應式係數、計算反應熱或 pH 值 | `game-fill.html` |
| **配對題 (Matching Pairs)** | 酸與共軛酸鹼對、官能基名稱與化學結構式、化合物與俗名/用途 | `game-match.html` |
| **是非題 (True/False)** | 澄清化學迷思（如：純水的 pH 值在高溫下是否仍為 7） | `game-tf.html` |
| **排序題 (Ordering)** | 實驗操作步驟（如：安全吸球操作、滴定步驟）、週期表原子半徑/游離能大小排序 | `game-order.html` |
| **記憶翻牌 (Memory Cards)** | 記憶常用元素符號與沉澱表（如：陽離子與陰離子的沉澱對照） | `game-memory.html` |

---

## Step 3：設計小遊戲 HTML 規範

每個遊戲均為**單一獨立的 HTML 檔案**，內嵌所有 CSS 與 JavaScript 程式碼。不可使用外部伺服器儲存數據，確保離線可用且載入速度快。

### 化學題型設計要點：
- **化學式顯示**：在網頁上應利用 `<sub>` 與 `<sup>` 標籤正確渲染化學式（如 `H<sub>2</sub>SO<sub>4</sub>`）。
- **即時解析回饋**：當學生答錯時，除了告知正確答案，必須提供**「化學原理解析」**（例如解釋為何反應向右移動，或為什麼該物質不溶於水）。

### 範例：化學式係數平衡填充遊戲設計（JS 數據結構）
```javascript
const questions = [
  {
    equation: "a N2 + b H2 → c NH3",
    hint: "請平衡此反應方程式，並依序輸入係數 a, b, c (以逗號隔開)",
    answer: "1,3,2",
    explanation: "1 莫耳的氮氣與 3 莫耳的氫氣反應，會生成 2 莫耳的氨氣。係數比 N2:H2:NH3 = 1:3:2。"
  }
];
```

### 範例：酸鹼滴定實驗步驟排序遊戲
```javascript
const steps = [
  { id: 1, text: "以蒸餾水清洗滴定管，再以欲裝盛的酸（或鹼）標準液潤洗 2~3 次。" },
  { id: 2, text: "將標準液裝入滴定管中，排除管尖氣泡，並記錄初始讀數。" },
  { id: 3, text: "用移液管吸取待測液置於錐形瓶中，並加入 2~3 滴指示劑。" },
  { id: 4, text: "開始滴定，過程中需不斷旋轉錐形瓶，直至指示劑呈現穩定的變色終點。" },
  { id: 5, text: "記錄滴定管的最終讀數，計算所消耗的標準液體積。" }
];
```

## Step 4：GitHub 自動發佈與 QR Code 生成

- 每個 HTML 檔案中應內嵌動態 QR Code 顯示腳本（利用 `https://api.qrserver.com/v1/create-qr-code/`）。
- 產生一個入口索引網頁 `index.html`，以列表形式呈現所有重點主題與其對應的網址和 QR Code。
- 收集使用者的 GitHub Access Token，建立或使用指定 Repository，將所有小遊戲 HTML 檔案上傳並啟用 GitHub Pages。
- 發佈完成後，回傳各個小遊戲的完整網址，並在對話中直接以 Markdown 圖片格式顯示 QR Code，供教師即時投影或複製使用。
