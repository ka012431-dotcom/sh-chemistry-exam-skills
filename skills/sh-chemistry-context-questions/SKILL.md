# 高中化學生活情境與探究實作非選擇題命題技能

## 技能概覽

本技能依使用者指定的高中化學單元，上網搜尋相關生活情境、綠色化學、科技應用與時事新聞，將真實素材轉化為具備「探究與實作」色彩的非選擇題，並匯出格式正確的 Word 文件。

- **五大題**，每大題含兩小題。
- **第(1)小題**：閱讀素材，解讀條件或回答基礎化學知識（Bloom 第2級：理解）。
- **第(2)小題**：承接第(1)題，結合化學單元進行計算、撰寫平衡化學反應式或解釋反應機制，達到應用或分析層次（Bloom 第3-4級）。
- **每大題皆含完整解析**（含解題關鍵、計算步驟與 Bloom 層次判定理由）。
- **化學結構與圖示支援**：若題目涉及化學實驗（如滴定管圖、反應位能圖、電化學電池裝置、相圖），呼叫 `sh-chemistry-diagram` 技能產生配圖插入 Word。
- **匯出 Word 文件**，化學式以格式化上下標正確呈現。

## 化學標記語法

在題目文字中，使用 `{}` 包住化學式，以利格式化輸出：

| 標記語法 | 說明 | 範例 |
|---------|------|------|
| `{H_2O}` | 分子式下標 | $\text{H}_2\text{O}$ |
| `{CO_2}` | 分子式下標 | $\text{CO}_2$ |
| `{SO_4^{2-}}` | 上下標並存（硫酸根） | $\text{SO}_4^{2-}$ |
| `{^{14}_6C}` | 前置質量數與原子序 | $_{6}^{14}\text{C}$ |
| `{->}` | 反應箭頭 | $\to$ |
| `{<=>}` | 平衡雙向箭頭 | $\rightleftharpoons$ |
| `{Delta H = -286 kJ/mol}` | 反應熱表示法 | $\Delta H = -286\text{ kJ/mol}$ |

## 處理流程

### Step 1：確認需求

向使用者確認以下資訊（未提供則詢問）：
- 化學單元名稱。
- 適用年級（高一必修化學、高二選修化學、高三選修化學）。
- 是否有特定的生活情境偏好（如：環境化學、綠色能源、食品科學、先進材料）。

### Step 2：網路搜尋生活情境與時事

使用 `search_web` 工具進行 3~5 次搜尋，尋找與指定化學單元相關的真實生活素材。例如：
- **環境/氣候**：溫室效應與溫室氣體、海洋酸化、臭氧層破壞。
- **綠色能源**：氫燃料電池、鋰離子電池、太陽能光電化學、電解水製氫。
- **食品科學/健康**：防腐劑、食品添加物、蛋白質變性、反式脂肪、油脂水解與皂化。
- **先進材料**：石墨烯、液晶、導電聚合物、形狀記憶合金、生物可分解塑膠。

### Step 3：設計題目與解析

每大題結構：
1. **情境素材段落**：提供背景資料或圖表。
2. **第(1)小題（理解）**：例如：指出反應物與產物、寫出官能基名稱、辨認同位素、說明某物質的物理性質。
3. **第(2)小題（應用/分析）**：例如：平衡化學反應式並計算反應熱、利用理想氣體方程式計算氣體體積、分析平衡移動方向、計算水溶液之 pH 值、比較沸點高低並以分子間作用力（氫鍵、偶極-偶極力、分散力）解釋。

---

### Step 4：化學實算驗算（必做，生圖與匯出前）

> ⚠️ **所有化學題目在產出前必須先跑 Python 實算**，防止化學計量、莫耳質量或平衡常數數值算錯。

**常見化學題型驗算速查**：

| 題型 | Python 驗算算式 |
|------|--------------|
| 限量試劑與產量 | `mol = mass / mw`，比對係數比，求得理論產量 = `限量試劑mol * 係數比 * 產物mw` |
| 理想氣體定律 | `P = n * R * T / V` 或 `V = n * R * T / P`（$R = 0.082$, $T = \text{temp\_c} + 273.15$） |
| 酸鹼稀釋與 pH | 強酸：`pH = -math.log10(c)`；弱酸：`[H+] = math.sqrt(Ka * C)` $\to$ `pH = -math.log10([H+])` |
| 熱化學能量換算 | `Energy = mol * Delta_H`，能量單位為 $\text{kJ}$ 或 $\text{kcal}$ |
| 半衰期計算 | `N_t = N_0 * (0.5) ** (t / t_half)` |

## 匯出 Word 與後處理流程

1. **生圖與渲染**：若有 `geometry`（化學實驗圖、位能圖等，規格見 `sh-chemistry-diagram`）或 `illustration`（情境氛圍插圖），呼叫腳本進行渲染。
2. **匯出 Word**：使用 Python 腳本將 `exam_data.json` 轉換為排版工整的 Word 文件（`exam_output.docx`），並自動將渲染完成的化學圖示與情境插圖插入對應段落。
3. **提供下載**：完成後將文件移至輸出目錄並呈現給使用者。
