# 高中化學段考命題審題技能

## 技能概覽

本技能支援兩種模式，協助教師完成高中化學段考的完整命題與審題流程，並完美結合 108 課綱化學科學習內容與 Bloom 認知分級。

**模式 A：出題模式**（全新命題）
1. 需求訪談 — 確認範圍（必修/選修化學）、題型（單選、多選、非選）、配分。
2. 規劃雙向細目表 — 章節 × 認知層次比例。
3. 生成題目 — 按 Bloom 四級分類產出。單選與多選題皆具備。
4. **化學圖示渲染** — 若有反應位能圖、實驗裝置、分子結構等需求，自動產生配圖（呼叫 sh-chemistry-diagram 技能）。
5. 格式輸出 — 題目卷、答案卷、雙向細目表（三份 Word），化學圖形自動插入對應位置。

**模式 B：審題模式**（審核現有考卷）
1. 接收考卷 — 使用者貼入文字或上傳圖片/Word。
2. 逐題審查 — 判定 Bloom 層次、單元歸屬、答案正確性與題目品質（特別是多選題的誘答力）。
3. 輸出分級報告 — 顯示統計與偏差提示（例如：計算題過多、記憶題過少）。
4. 格式輸出 — 僅產出雙向細目表（一份 Word）。

## 處理流程

### Step 1：需求確認（必做）

向使用者確認以下資訊（未提供則詢問）：

| 項目 | 說明 |
|------|------|
| 課程範圍 | 必修化學 / 選修化學 I~V（說明章節與版本，如康軒、翰林、南一） |
| 學期 & 次別 | 第一學期第二次段考 等 |
| 題型需求 | 單選題幾題（五選一）、多選題幾題（五選二或三，需說明部分給分規則）、非選擇題幾題 |
| 難度目標 | 參考 Bloom 各級比例（預設：記憶 15%、理解 25%、應用 35%、分析 25%） |
| 模式 | **A. 出題**（全新產出題目卷+答案卷+細目表） / **B. 審題**（審核現有考卷，只產細目表） |

---

### Step 2：建立雙向細目表

規劃雙向細目表，包含：
- **縱軸**：教材章節（如「物質的分類」、「原子構造與週期表」、「化學反應與計量」、「化學鍵與物質結構」等）
- **橫軸**：認知層次（記憶 / 理解 / 應用 / 分析）
- **細格**：分數（題數），例如 `6（2）` 代表該單元在該層次佔 6 分（共 2 題）

**高中化學段考建議比例**：

| 層次 | 化學科對應特徵 | 建議佔比 |
|------|--------------|---------|
| 第1級：記憶 | 記憶化學符號、沉澱表、電子組態規則、名詞定義（如同位素、官能基） | 15% |
| 第2級：理解 | 解釋化學週期性趨勢、物質性質差異（如沸點高低）、平衡移動方向（勒沙特列） | 25% |
| 第3級：應用 | 進行化學計量計算、理想氣體計算、pH值計算、電化學摩爾數換算 | 35% |
| 第4級：分析 | 分析反應機構、畫出/解讀位能圖、判定有機異構物數目、分析實驗數據 | 25% |

---

### Step 3：題目生成（出題模式 A 專用）

依雙向細目表生成題目，每題須標註：
- 題號、題型（單選 / 多選 / 非選）
- Bloom 等級與判定理由
- 正確答案（多選題需寫明複選答案）+ 詳細解題過程
- **化學圖示需求**（若需要，填寫 `geometry` 欄位）

**高中化學題型規範**：
1. **單選題**：五選一（A/B/C/D/E），必須有唯一正確答案。
2. **多選題**：五個選項，每題有 2~3 個正確答案。需註明部分給分標準：
   * *標準多選計分*：錯一個選項得 3/5 分（或扣該題部分分數），錯兩個得 1/5 分，錯三個以上（含三個）或未作答者該題以零分計。
3. **答案分佈**：單選題正確答案應平均分佈於 A/B/C/D/E，多選題正確答案組合亦應隨機化，避免規律性。

---

### Step 4：化學自我驗算（必做，出題模式下產出前）

> ⚠️ **化學計算題在產出前必須先跑 Python 實算**，避免摩爾質量、氣體常數、pH 對數計算出現數值錯誤。

**常見化學計算驗算速查**：
- **化學計量**：限量試劑判定、理論產量與產率計算（$\text{mol} \times \text{molecular weight}$）。
- **理想氣體**：$PV = nRT$，注意常數 $R = 0.082\text{ atm}\cdot\text{L}/(\text{mol}\cdot\text{K})$，溫度需換算為絕對溫度 $K$。
- **酸鹼平衡**：$\text{pH} = -\log[\text{H}^+]$，常溫下 $\text{pH} + \text{pOH} = 14$，強酸鹼稀釋與弱酸鹼解離平衡（$K_a, K_b$）。
- **熱化學**：赫斯定律（反應熱相加減）、生成熱與燃燒熱計算。

## 化學格式標記語法

在題目與解析文字中，使用 `{}` 包裹化學式與物理量標記，以便於 Word 中渲染為正確的上標、下標或特殊化學符號：

| 標記語法 | 說明 | 渲染範例 |
|---------|------|---------|
| `{H_2O}` | 下標（分子式） | $\text{H}_2\text{O}$ |
| `{H_2SO_4}` | 多重下標 | $\text{H}_2\text{SO}_4$ |
| `{Fe^{3+}}` | 上標（離子價數） | $\text{Fe}^{3+}$ |
| `{^{14}_6C}` | 前置上角標與下角標（同位素） | $_{6}^{14}\text{C}$ |
| `{K_sp}` | 下標文字 | $\text{K}_{sp}$ |
| `{->}` | 化學反應箭頭 | $\to$ |
| `{<=>}` | 可逆反應平衡箭頭 | $\rightleftharpoons$ |
| `{Delta H}` | 反應熱符號 | $\Delta H$ |
| `{K_a}` | 弱酸游離常數 | $\text{K}_a$ |
| `{[H^+]}` | 濃度表示法 | $[\text{H}^+]$ |

## 雙向細目表與審題報告產出

在審題模式（模式 B）下，AI 會對使用者貼入的試題進行逐題審查，判定其單元歸屬及 Bloom 認知層次。
審查完畢後，JSON 檔中應包含 `review_report` 欄位，呼叫後處理腳本匯出雙向細目表與審題報告 Word 文件，供教師下載。
格式對照如下：
- **雙向細目表**：整理各單元於各 Bloom 層次的分數分佈，檢查是否偏離建議佔比。
- **審題報告**：指出考卷中是否有題目語意不清、多選題選項誘答力不足、計算數字設計不良或標準答案重複等品質問題，並提供修改建議。
