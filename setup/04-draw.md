# 生圖（AntiGravity 版）

## 支援的生圖管道

| 路線 | 說明 |
| :--- | :--- |
| **路線 A：內建工具** | 直接呼叫 AntiGravity 的內建生圖工具（如有配備），以自然語言進行生成，無需設定任何 API Key。 |
| **路線 B：API 串接** | 設定 `OPENAI_API_KEY` 環境變數，使用 DALL-E 等第三方 API 進行繪製。 |

## 建議生圖提示詞（Prompt）格式

使用以下結構提供給生圖工具或 AI，能獲得更精準與優質的圖片：
```text
生成一張圖片：
- 用途：[例如：海報背景、網頁插圖、App Icon]
- 尺寸比例：[例如：1:1, 16:9, 4:3]
- 主題：[主體是什麼，例如：家長會活動宣傳]
- 畫面內容：[主體與背景細節描繪]
- 風格：[例如：扁平插畫、現代極簡、3D 渲染、粉彩]
- 色彩：[色彩調性，例如：溫暖和煦的馬卡龍色系、科技藍]
- 文字：[畫面中若要出現的字（注意：生圖軟體中文容易出錯，重要文字建議後製）]
- 限制：[避開哪些內容，例如：不要寫實照片、不要太過雜亂]
- 輸出路徑：[例如：./assets/images/poster_bg.png]
```

⚠️ 安全與整理原則：
* 請將生成好的正式圖片存入專案目錄的 `assets/` 或 Obsidian 的附件夾中。
* 暫存、測試用的草稿圖，請勿一併 commit 提交至 GitHub 儲存庫。
